# What the Water Keeps

Alice & Daniel — a premium narrative puzzle adventure planned for Android and iOS, with Steam as an option.

[Read the complete story and game plan](docs/alice-and-daniel/README.md).

The package contains the story bible, a complete first-draft screenplay for seven chapters and three endings, twelve interaction designs, and an estimated production/release plan. This repository currently contains planning documents; no playable game is claimed.

Working title. Version 1.0 planning package, 22 September 2026.
